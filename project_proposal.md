The project focuses on designing and implementing a small programming language called SimpleLang with Python under the hood.

The language supports variables, arithmetic and logical expressions, conditional statements, loops, functions, and recursion.

The interpreter tokenizes source code, parses it into an Abstract Syntax Tree (AST), and executes it according to the language's semantics.

In addition to basic program executions, we plan to include educational features that allow users to inspect tokens, AST structures, and variable environments. These features will help demonstrate how programming languages work internally.

The project applies several concepts from the course, which are syntax, semantics, scope, control flow, functions, recursion, and runtime environments.
