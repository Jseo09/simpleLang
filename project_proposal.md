Our project focuses on designing and implementing a small programming language called SimpleLang using Python.

The language will support variables, arithmetic and logical expressions, conditional statements, loops, functions, and recursion.

The interpreter will tokenize source code, parse it into an Abstract Syntax Tree (AST), and execute it according to the language's semantics.

In addition to basic program execution, we plan to include educational features that allow users to inspect tokens, AST structures, and variable environments. These features will help demonstrate how programming languages work internally.

The project will apply several concepts from the course, including syntax, semantics, scope, control flow, functions, recursion, and runtime environments.
